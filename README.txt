AINKTANZ - GitHub Deployment

Upload to GitHub

1. Create a new repository on GitHub.
2. Upload all website files to the repository.
3. Make sure index.html is in the root folder.
4. Keep index.html and aink tanz-background.jpg together.
5. Go to Settings > Pages.
6. Under Build and deployment, select Deploy from a branch.
7. Select the main branch and /(root).
8. Click Save.

Your website will be published using GitHub Pages.
